ABOUT THE PROJECT

Minecraft, Amplified. One cinematic gateway for every mod and every version — honest to the byte.

THE STORY

BUILT BY A GAMER, FOR GAMERS

BLauncher MOD was born from a simple frustration: discovering a mod and getting lost across five sites with fake download buttons. We wanted one beautiful, insanely fast portal that serves real data, real files and zero ads — a launcher-quality hub, amplified.

★ Made & sponsored by Arif The Gamer. The Android launcher project (BLauncher) and this portal are siblings in the same dream: a smoother Minecraft journey on every device.

ARCHITECTURE

OFFICIAL APIs ONLY

  • Modrinth v2 — direct official REST API, cached & debounced in-browser.
  • CurseForge — official API through a server-side Cloudflare Function; your key never ships to clients.
  • Mojang — official piston-meta manifest for every true version 1.0 → 26.3.
  • Stack — pure HTML/CSS/ES2020, no frameworks, Cloudflare Pages ready.

PROMISES

HONEST TO THE BYTE

  • Never fabricated data: no invented mods, versions or stats.
  • Missing API? Clear setup warning, not a fake number.
  • Official files only, from official CDNs.
  • Zero tracking, zero ads, zero forced intros.

SETUP WARNINGS HANDLED

CURSEFORGE KEY

The CurseForge portal requires a server-side key. Follow API_SETUP.md (in the repository) to publish the key as a Cloudflare environment variable. Until then the site shows a friendly warning — and everything else keeps working.
